# Playbook refactor

1. Capturer la baseline : tests, bundle, requêtes, CPU, mémoire.
2. Caractériser le comportement.
3. Modifier par petits pas.
4. Tester après chaque pas.
5. Mesurer après avec la même méthode.
6. Documenter le delta et le rollback.

Interdictions : mélanger feature et refactor, supprimer des tests, optimiser sans mesure.
