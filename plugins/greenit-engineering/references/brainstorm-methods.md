# Méthodes de brainstorm

- **Brainwriting** : écrire 3 idées, passer à voisin, 3 tours.
- **SCAMPER** : substituer, combiner, adapter, modifier, put to other uses, éliminer, réorganiser.
- **Cartographie des parcours** : chaque étape, chaque requête, chaque donnée.
- **Cycle de vie** : spécifications, conception, réalisation, production, usage, maintenance, fin de vie.
- **Tiers** : terminaux, réseau, datacenter.
- **Sobriété / efficacité / transition**.

Règle : divergence sans filtrage, puis convergence avec matrice impact/effort.
