# GreenIT Engineering

GreenIT Engineering fournit des skills de terrain pour réduire l’impact d’un codebase : refactor, correctif, proposition technique, brainstorm, benchmark et revue GreenIT.

## Installation

```text
/plugin install greenit-engineering --marketplace <owner>/<repo>
```

## Usage

`refactor` et `fix` imposent une mesure avant/après et des tests. `proposal` produit une décision argumentée. `brainstorm` génère puis priorise des idées. `benchmark` compare des solutions. `greenit-review` audite le code par tier et cycle de vie.

## Prérequis

Python 3.10+ et Git. Les scripts de mesure sont optionnels et échouent proprement si un outil manque. Aucun code n’est exécuté hors du workspace sans accord explicite.
