# Facteurs locaux

`factors.local.example.csv` ne contient que l’en-tête : les valeurs NegaOctet ne sont pas publiées.

Pour un usage local autorisé :

```bash
cp factors.local.example.csv factors.local.csv
# remplir factors.local.csv avec les valeurs sous licence
```

`factors.local.csv` est ignoré par Git (`*.local.csv`).
