# RWEB 5.0.0 — synthèse opérationnelle

**RWEB** (Référentiel de bonnes pratiques pour un web responsable) est publié par le Collectif Green IT. La version 5.0.0 comporte **119 critères** répartis sur **7 étapes du cycle de vie** :

1. Spécifications
2. Conception
3. Réalisation
4. Production
5. Utilisation
6. Support et maintenance
7. Fin de vie

Chaque fiche précise l’impact environnemental, la mise en œuvre, la priorité (1 à 5), le tier concerné et le profil (développeur, intégrateur, chef de projet, etc.).

Source : `[S06]`, fiches officielles `https://rweb.greenit.fr/fr/fiches`. Le bundle cite les fiches utilisées et n’en recopie pas l’intégralité.

## Usage

- Utiliser RWEB pour les bonnes pratiques web concrètes : poids, requêtes, cache, images, polices, hébergement, fin de vie.
- Rattacher chaque constat à une étape du cycle de vie et à un tier.
- Ne pas présenter RWEB comme un référentiel réglementaire : c’est un référentiel communautaire.
- Croiser avec le RGESN pour les critères réglementaires et avec GR491 pour la vision cycle de vie.

## Limite

RWEB est centré sur le web. Il ne couvre pas finement les applications mobiles natives, les systèmes embarqués ou les services hors ligne.
