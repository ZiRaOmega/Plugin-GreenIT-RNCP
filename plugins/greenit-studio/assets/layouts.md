# Layouts de slides

| Layout | Usage | Champs |
|---|---|---|
| `title` | Ouverture | `title`, `subtitle`, `notes` |
| `section` | Transition | `kicker`, `title`, `subtitle` |
| `bullets` | Message | `kicker`, `title`, `bullets`, `source` |
| `metrics` | 3 chiffres | `cards[]` avec `value`, `label`, `detail` |
| `chart` | Figure | `image`, `takeaway`, `source` |
| `matrix` | Impact/effort | `items[]` avec `label`, `impact`, `effort` |
| `timeline` | Plan | `items[]` avec `phase`, `label`, `start`, `end` |
| `quote` | Citation | `quote`, `attribution` |
| `closing` | Fin | `title`, `subtitle`, `bullets` |

Règles : 1 message par slide, 3 puces max, 1 visuel, source en pied de page, notes de 60–90 s.
