# Spécification PPTX

- 16:9, 13,333 × 7,5 pouces.
- 12–15 slides pour 15 minutes.
- Palette `assets/theme.json`.
- Police `Liberation Sans`, titre 30–34 pt, corps 18–20 pt, source 9–10 pt.
- 3 puces max, 1 visuel, titre-message.
- Notes 60–90 s par slide.
- Pied de page source sur chaque slide de données.
- Pas de photos stock, pas d’icônes décoratives, pas de 3D.
- Export PDF via LibreOffice.
