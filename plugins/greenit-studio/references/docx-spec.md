# Spécification DOCX

- Format A4, marges 2,2 cm.
- Corps 10,5–11 pt, interligne 1,25.
- Titres verts, hiérarchie H1/H2/H3.
- Couverture 1600×1000, générée si absente.
- Sommaire statique + champ TOC.
- Tableaux 9–10 pt, en-tête vert, lignes alternées, en-tête répété.
- Figures centrées, légende, texte alternatif.
- Encadrés : info, hypothèse, limite, décision.
- En-tête et pied de page avec pagination.
- Propriétés : titre, auteur, sujet, mots-clés, langue `fr-FR`.
- PDF via LibreOffice.
