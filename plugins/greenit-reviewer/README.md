# GreenIT Reviewer

Revue indépendante des livrables d’audit GreenIT : PDF, PPTX, figures, métriques, RGESN et dossier RNCP39388.

## Installation

```text
/plugin install greenit-reviewer --marketplace <owner>/<repo>
```

## Skills

- `design-review` : chevauchements, marges, typographie, palette, glossaire, données, graphiques, RNCP.
- `sanitize-ai-text` : détection et remplacement des caractères/formulations IA.
- `content-challenge` : agent indépendant qui challenge les livrables.

## Agent

`independent-challenger` : lecture seule, verdict par livrable, questions et corrections attendues.
