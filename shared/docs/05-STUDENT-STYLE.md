# Style étudiant

## À faire

- Écrire à la première personne du pluriel : « nous avons », « notre groupe ».
- Définir les termes techniques avant de les utiliser.
- Donner des ordres de grandeur et des fourchettes.
- Utiliser des encadrés : « À retenir », « Notre hypothèse », « Notre limite », « Notre décision ».
- Expliquer les calculs avec un exemple.
- Citer les sources `[Sxx]`.
- Assumer les données manquantes.
- Terminer par les limites et les prochaines étapes.

## À éviter

- Le jargon non défini.
- Les chiffres sans unité.
- Les fausses précisions (`1,234567 kg`).
- Les gains non mesurés présentés comme mesurés.
- L’addition de gains qui se recouvrent.
- Les formules « neutre en carbone », « 100 % vert », « compensation » comme argument.
- Les slides surchargées.

## Structure type

1. Contexte et problème.
2. Méthode et UF.
3. Résultats et hotspots.
4. Diagnostic.
5. Actions.
6. Limites.
7. Conclusion.
